# Financial Analysis Dashboard

## Project Overview
Developed an interactive Financial Analysis Dashboard using Excel to analyze revenue, expenses, profit trends, and key business insights through data visualization.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Data Visualization

## Features
- Revenue Analysis
- Expense Tracking
- Profit Margin Insights
- Monthly Comparison Dashboard

## Project Files
- Excel Dashboard File
- Dashboard Visualizations
- Financial Analysis Reports
